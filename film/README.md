# Move. Be seen. · 鼠标一动，界面就回应

20 秒 / 1920×1080 / 60fps。五种指针微交互，每种包含 **适用场景 + 可复用 AI 提示词 + 操作演示**。

|控件|适用场景|演示机制|
|---|---|---|
|流光边框 · Lucian 228|功能卡片|统一光源跟随鼠标，照亮相邻卡片边缘。|
|变形光标 · Lucian 314|品牌官网|指针进入按钮、文字、图片、链接时改变形态。|
|照片拖尾 · Lucian 323|创意作品集|移动生成照片，点击后扇形展开。|
|代码透视镜 · Lucian 325|组件教学|圆形遮罩显示代码，点击扩张至整卡。|
|点阵波纹 · Lucian 363|科技首页|移动生成轻波，点击释放强波。|

片尾：**场景 + 动作 + 反馈。让每个动作，都被回应。**

## 制作提示词

```text

沿用黑色 Bento 网格、Inter 大标题、中文短句与橙粉紫标题渐变；控件内部保留原站对应配色。

第一帧有主体和大字；顶部常驻“鼠标一动，界面就回应”。
```

## 完整可复用 AI 提示词

### 01 流光边框
为产品首页制作四张功能卡片。用同一个鼠标坐标驱动径向光源，让光线跨过卡片缝隙并照亮相邻边缘，内部只轻微提亮；指针离开时平滑淡出。不要让光遮住文字，保持卡片可点击。触屏使用按下位置反馈，并支持减少动态效果。

### 02 变形光标
为品牌官网制作跟随指针的变形光标。悬停按钮时轮廓包裹按钮，悬停正文时缩为细线，悬停图片时变成带“查看”的圆，链接上显示箭头。形态与目标命中区域一致，切换平滑，离开页面恢复。自定义光标不拦截点击；触屏保留普通控件操作。

### 03 照片拖尾
为创意作品集制作照片拖尾。根据指针移动距离逐张生成照片，轻微旋转和弹入，停留后缩小淡出；点击时在点击位置扇形展开五张照片。限制同时存在的照片数量，保持内容可读。照片层不拦截页面操作，支持减少动态效果，触屏点击也可触发。

### 04 代码透视镜
为组件教学页制作代码透视镜。同一个卡片位置叠放 UI 与对应代码，用跟随鼠标的圆形遮罩显示代码层，圆边缘有细绿色描边。点击时从点击位置扩展到全卡，第二次点击收回；支持触屏点击、键盘切换和减少动态效果。UI 和代码必须对应，不移动底层内容。

### 05 点阵波纹
为科技产品首页制作交互点阵背景。指针移动时产生轻微同心波，点击时产生更强波纹，按距离与时间计算波前，点的尺寸与颜色随波传播，多个波纹可叠加后衰减。限制计算量与波纹数量，背景不遮挡正文。触屏点按可触发，减少动态模式保留静态或短暂反馈。


## 制作与复现

1. 核对 [Lucian UX/UI Prompt](https://lucianlabs.dev/uxui-prompt/) 的目录、源码和交互状态，来源与分镜见 [treatment.md](treatment.md)。
2. 用确定性的 Canvas 函数绘制五个控件。七个 Bento 面板保留身份并重排，UI / 代码层与指针坐标一致。
3. 九帧检查后两轮修改：镜片避开空代码区域，调整示例卡片文字间距；照片展开时弱化背景标题、收束旧照片，形态说明随光标实际到位切换。
4. Python / numpy 合成 120 BPM、2/4 拍、20 小节音轨，按操作时间混入音效，最后和弦在 18 秒，末尾 0.8 秒淡出。
5. Playwright 逐帧调用 draw(i/60)，输出 1,200 张 JPG；FFmpeg 编码 H.264 Main / yuv420p / AAC，启用 faststart 和每秒关键帧。
6. 从真实成片抽帧检查，测试 20 秒完整播放及跳转。验收见 [QA.md](QA.md)。

```sh
# 需要 Node.js、Python 3 + numpy、Chrome、FFmpeg
npm install
python3 make_audio.py
npm run stills
npm run render
sh encode.sh
```

Chrome 默认使用 macOS 安装路径。其他平台运行前设置 CHROME_PATH。
`index.html` 是影片时间轴，供播放、跳转、改画面；它不是接受真实鼠标交互的演示站点。
使用 huashu-motion 可运行 `om studio . --no-open` 打开可定位帧的预览工作台。

## 文件

- index.html：五种效果、分镜、字幕、Bento 重排、draw(t)。
- render.mjs / encode.sh：逐帧渲染与 MP4 编码。
- make_audio.py / assets/sound.wav：确定性配乐和音效。
- assets/fonts / vendor：本地字体、GSAP、OM 运行时及许可。
- treatment.md / QA.md：来源、分镜、提示词、验收。
