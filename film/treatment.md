# 鼠标一动，界面就回应

20 秒 / 1920×1080 / 60fps；代码绘制、无口播，原创合成配乐与音效。
沿用本系列黑色 Bento 布局，五项的 UI 使用源站配色：紫蓝光、奶白、暖白照片、绿透视镜、青蓝点阵。中文为教学重写；示例价格不是产品报价。

## 已核实来源（2026-10-27）

源站：https://lucianlabs.dev/uxui-prompt/ 。核对目录、对应 HTML/JS 与交互截图。
1. #228 glow-border-cards：指针驱动共享光源，照亮邻近卡片的边缘；离开后淡出。
2. #314 morphing-cursor：按钮处包裹轮廓、文字处变细线、图片处显示查看圆、链接处显示箭头。
3. #323 photo-trail：按移动距离生成照片，照片短暂留存后缩小消失；点击产生扇形照片。
4. #325 xray-code-lens：同一位置的 UI / 代码两层；圆形遮罩跟随指针，点击扩展至全卡。
5. #363 dot-grid-wave：鼠标移动产生小波纹，按下产生大波纹；点阵颜色和大小随波前改变。

本片独立重绘，保留机制，不剪入截图。照片为程序绘制的山景教学素材。

## 导演与节奏

- 主信息：反馈要跟着意图走。场景 + 动作 + 反馈。
- 语言：cursor-demo，固定身份 Bento 卡片连续重排。沿用获认可的系列结构，跳过三方向选稿。
- 120 BPM、2/4 拍，每小节 1 秒，首拍 0 秒。0/2/5/8/11/14/17 秒章节均在小节线。
- 能量：开场 6 → 流光 4 → 变形 6 → 照片 8 → 透视 6 → 波纹 8 → 总结 3。
- 所有转场约 0.6 秒，在稳定阅读时保留控件内部运动；照片段四个落点构成中段密集节奏。
- 18 秒回到主和弦，最后 0.8 秒自然淡出，20 小节结束。
- 首帧五控件与标题齐全，不黑屏。顶部常驻钩子。末尾五项再次同屏编号。

## 连续性与四张关键帧

五张控件卡保留身份：总览 → 放大第 1 项 → 第 1 项归入缩略带、第 2 项放大 → 同理第 3/4/5 项 → 回总览。
标题、提示词和控件三层分开；移动只改变取景，动作结果保持到转场后半段。
四张主帧：0.6s（钩子）、9.8s（照片爆发）、12.7s（透视机制）、19.2s（总结）。另取九帧总览检查。

## 完整可复用 AI 提示词

### 01 流光边框
为产品首页制作四张功能卡片。用同一个鼠标坐标驱动径向光源，让光线跨过卡片缝隙并照亮相邻边缘，内部只轻微提亮；指针离开时平滑淡出。不要让光遮住文字，保持卡片可点击。触屏使用按下位置反馈，并支持减少动态效果。

### 02 变形光标
为品牌官网制作跟随指针的变形光标。悬停按钮时轮廓包裹按钮，悬停正文时缩为细线，悬停图片时变成带“查看”的圆，链接上显示箭头。形态与目标命中区域一致，切换平滑，离开页面恢复。自定义光标不拦截点击；触屏保留普通控件操作。

### 03 照片拖尾
为创意作品集制作照片拖尾。根据指针移动距离逐张生成照片，轻微旋转和弹入，停留后缩小淡出；点击时在点击位置扇形展开五张照片。限制同时存在的照片数量，保持内容可读。照片层不拦截页面操作，支持减少动态效果，触屏点击也可触发。

### 04 代码透视镜
为组件教学页制作代码透视镜。同一个卡片位置叠放 UI 与对应代码，用跟随鼠标的圆形遮罩显示代码层，圆边缘有细绿色描边。点击时从点击位置扩展到全卡，第二次点击收回；支持触屏点击、键盘切换和减少动态效果。UI 和代码必须对应，不移动底层内容。

### 05 点阵波纹
为科技产品首页制作交互点阵背景。指针移动时产生轻微同心波，点击时产生更强波纹，按距离与时间计算波前，点的尺寸与颜色随波传播，多个波纹可叠加后衰减。限制计算量与波纹数量，背景不遮挡正文。触屏点按可触发，减少动态模式保留静态或短暂反馈。
